# Context budget (Crew)

Goal: fewer tokens before first edit; less AXI/transcript bloat.

Full instrument set (anti-goals, edit maps, TDD contracts, taste freeze):
`docs/crew-instruments.md`.

## Primary (spawns / answers)

- Briefs: file/section **allowlist**, not "read X in full." Prefer path:line
  edit maps; ban discovery-cat tours of sibling modules.
- Link packet sections; do not paste essays already on the share board.
- Contested UI after a scout: mandatory Anti-goals block.
- Expensive ships: Thin TDD Contract before spawn when seams are known.
- Astra **xHigh** only for hard art/adversarial after an owner wireframe or
  plate-ref pack exists (Taste Freeze Gate). Fable/high for glue/rules.
- Merge closeout: `bin/finish` (never `bin/answer`). Tip-sync if needed,
  then finish - **zero worker tokens**. Do not wake the model for done/usage.
- Prefer a **new** short follow-up task over extending a long session.

## Workers (also in WORKER.md)

- Open only brief-named paths; path-limited search; tests/edits before broad reading.
- Honor Edit-Map / TDD contract order; no wholesale module archaeology.
- AXI once at the end if required: no `snapshot --full`, no console/network/perf spam, ≤2 screenshots on disk not in-chat.
